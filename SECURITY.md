# Security Policy

## Supported Versions

The following table lists the security support status for versions of `ckodex-oskal`:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

The CKODEX project takes security, cryptographic integrity, and supply chain assurance seriously.
If you discover a security vulnerability, flaw in vector state transitions, or cryptographic defect:

1. **Do NOT open a public GitHub issue.**
2. Send an encrypted or direct email to `security@ckodex.io` with:
   - Detailed description of the vulnerability.
   - Proof-of-concept exploit or reproducible test vector.
   - Potential blast radius and mitigation ideas.
3. You will receive an acknowledgment within 24 hours.
4. We coordinate a responsible disclosure timeline (typically 90 days or less).
