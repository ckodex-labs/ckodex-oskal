Tutorials guide you through hands-on learning experiences from scratch. They are designed to take a developer, platform engineer, or security engineer through complete working implementations of OSKAL without requiring prior familiarity with the codebase.

## Learning Objectives

- Understand how declarative control bindings and runtime observations interact.
- Execute an end-to-end assurance evaluation resulting in an Ed25519-signed `ControlReceipt`.
- Embed the OSKAL assurance engine into an in-process Go application or CI/CD test runner using `pkg/oskal`.
